One control core. Five superstacks.
A billion parameters that actually run.

A foundation-model architecture where every token passes through a shared control core, which routes it into deep domain banks, decides how far into them it goes, and decides whether to send it round again. Built at 1.00 B, verified by test, and costed to 9 T on the same code path. Every number below is generated from the repository, not typed in.

Architecture

What a token actually does

Stage I of the core owns the causal KV cache for the whole stream. The router picks k superstacks per token, a focus scalar sets how deep it goes, and a halting head decides whether it loops. Superstacks keep a sparse stack-local cache — the subset of earlier tokens routed to the same stack — plus a bridge onto the core's history. That pair is what makes cached decoding reproduce teacher forcing exactly.

The test rung

1,001,730,811 parameters, measured on a CPU

A small core and five general-purpose superstacks, with every mechanism of the full design present: two-stage core, top-2 routing, the bridge, the focus ladder, the ponder loop, and spectral blocks in the science stack. It instantiates, runs, decodes and trains.

Fifteen of twenty findings against the source specification. corrected means the plan's number or mechanism was wrong and the code uses a different one; found means a bug nobody had planned for, surfaced by a test.

The originating question

"What if I double the water over the waterfall?"

Not "it doubles". Steady open-channel flow has two different exact answers depending on which depth you mean, and they disagree by 4.7 %. The solver converges to the analytic normal depth from a starting state far from equilibrium, then recovers Manning's exponent on its own.

Measured

The training run, including where it failed

One phase-1 run at the 34 M rung: 800 steps, 755 s, CPU. The loss fell hard and the router stayed healthy. Graded by free-running generation against independent computation, four of five task families came out at or below a baseline that ignores the prompt entirely. That is reported here because a build whose only published numbers are the good ones is not a measurement.
