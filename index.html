EarthFlight

Photorealistic web flight simulator over real-world terrain.

Controls

  • Mouse — pitch & roll (click canvas to capture)
  • A / D — rudder (yaw)
  • W / S — throttle up / down
  • Shift — afterburner / full throttle
  • G — gear   B — airbrake
  • C — cycle camera   Tab — switch aircraft
  • R — reset attitude   Esc — release mouse / menu
